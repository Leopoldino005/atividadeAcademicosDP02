# Projeto Academico - ASP.NET Core MVC (CRUD Aluno)

Este projeto implementa o CRUD completo de **Aluno** em ASP.NET Core MVC (.NET 8.0), pronto para ser aberto e executado no **Visual Studio Code**.

## Como executar no Visual Studio Code

1. Extraia a pasta `Educacional` deste arquivo ZIP.
2. Abra o **Visual Studio Code**, clique em **Arquivo > Abrir Pasta...** (`File > Open Folder...`) e selecione a pasta `Educacional`.
3. Abra o terminal integrado (`Ctrl + '`) e execute:
   ```bash
   dotnet run --project Academico/Academico.csproj
   ```
4. Acesse no navegador a URL exibida no terminal (ex.: `http://localhost:5149` ou `https://localhost:7227`).
